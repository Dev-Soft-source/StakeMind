# Pain points and market gaps

## User pain points

- Hard to compare validators with consistent metrics across subnets.
- Reward performance is visible in fragments, not as a trustworthy portfolio timeline.
- Risk signals (concentration, downtime, volatility) are not surfaced in one place.
- Many tools emphasize wallet actions over decision support.
- Historical context is missing, so users stake reactively instead of with evidence.
- Delegation take, subnet exposure, and redelegation impact are difficult to reason about before signing.

## Product gaps StakeMind should fill

- Unified validator intelligence with documented scoring inputs.
- Historical reward and APY windows backed by stored snapshots.
- Portfolio diversification and subnet exposure analytics.
- Read-only trust path before any write or automation features.
- Clear non-custodial boundaries: connect wallet, never store private keys.

## Out of scope for early phases

- Multi-chain staking aggregation.
- Institutional custody.
- Autonomous reallocation before explicit user trust and policy controls.

## Validation signals for Phase 2

- Users can explain why one validator ranks above another.
- Users can inspect stake and reward history without manual chain queries.
- Users can compare validators without executing a transaction.
